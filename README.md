# Actnet Flow Releases

This source-free repository publishes official Windows installers and update metadata for Actnet Flow, the proprietary invoice-extraction and SoftOne import workflow from Actnet Tax Solutions S.A.

## Download and access

Installers are published only on the [GitHub Releases page](https://github.com/Actnet-Tax-Solutions-S-A/Actnet-Flow-Releases/releases). Compare the downloaded file against `SHA256SUMS.txt` included with each release before running it.

Downloading Actnet Flow does not grant service access. Pilot users must have an invite-only account issued for their client organization.

## Pilot warning

Early pilot installers may be unsigned. Windows can therefore show an unknown-publisher warning. Signing is required before broad production rollout; release notes will state the signing status explicitly.

## Security and source code

Actnet Flow is proprietary. Source code, internal documentation, credentials, customer data, invoices, and master workbooks are never published here. Report security issues through this repository's private vulnerability-reporting form rather than a public issue.

No open-source license is granted by this repository.

## Development and update delivery

The current application source is maintained in Actnet Tax Solutions S.A.'s private Actnet-Flow repository. Public installer/download problems can use this repository's [issue form](https://github.com/Actnet-Tax-Solutions-S-A/Actnet-Flow-Releases/issues/new/choose). Development is tracked on the organization's private Actnet Flow development board.

Approved release assets will be published here. Automatic in-app updates are being prepared separately; this repository currently has no published application release.
